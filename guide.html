Guide

Welcome to the AGE-C (Age and Cinema) data explorer! This guide will help you navigate and search through our comprehensive database of films, biographies, and cinematic data.

Getting Started

Opening the Search Panel

  • Click “Search and filters” button to open the search panel
  • Use keyboard shortcut: Press Ctrl+K (or Cmd+K on Mac) to toggle search panel

Basic Search

  1. Enter your search query in the search box at the top of the page
  2. Type at least 3 characters to enable the search button
  3. Click “Search” or press Enter to find results
  4. Click “Reset” to clear your search and start over

Understanding Results

  • Total results count is displayed at the top
  • Summary statistics show the breakdown by type (films, biographies)
  • Results are paginated with 25 items per page
  • Click on any result to view detailed information

Advanced Filtering

Available Filter Categories

The AGE-C database includes these filter categories:

Film Filters

  • Film type: Feature films, documentaries, short films, etc.
  • Genre: Action, comedy, drama, horror, and many more
  • Production country: Where the film was produced
  • Release year: When the film was released
  • Release type: Theatrical, TV, streaming, etc.
  • Awards: Films that have won or been nominated for awards

Person Filters

  • Role: Director, actor, producer, writer, etc.
  • Gender: Male, female, non-binary
  • Nationality: Country of origin
  • Birth year: When the person was born

Character Filters

  • Character age: Age groups of characters in films
  • Character gender: Gender representation of characters
  • Character sexuality: Sexual orientation of characters
  • Character origin: Where characters are from
  • Character class: Social class of characters
  • Character profession: Jobs and careers of characters
  • Character ability: Physical or mental abilities
  • Assisted mobility: Characters using mobility aids

Using Filters

  1. Expand a filter category by clicking on its name
  2. Search within filters if there are many options (appears automatically for categories with 15+ items)
  3. Select multiple options by checking multiple boxes
  4. Choose filter logic:
    • “Match all”: Results must match ALL selected filters (AND logic)
    • “Match any”: Results can match ANY of the selected filters (OR logic)
  5. See current filters displayed as removable tags
  6. Remove individual filters by clicking the × on the filter tag
  7. Clear all filters using the “Clear all filters” button

Filter Combinations

Some filters work together to create more specific searches:

  • Role + Gender: Find female directors or male actors
  • Genre + Production: Find action films from specific countries
  • Character age + Character gender: Find films with older female characters

Sorting Results

Available Sort Options

  • Person name (A-Z): Alphabetical order by person name
  • Person name (Z-A): Reverse alphabetical order by person name
  • Film title (A-Z): Alphabetical order by film title
  • Film title (Z-A): Reverse alphabetical order by film title

How to Sort

  1. Look for the “Sort by” dropdown above the results
  2. Select your preferred sorting option
  3. Results update automatically when you change the sort order

Data Insights and Visualizations

Understanding the Charts

The data explorer includes interactive charts showing:

  • Films released per year: Distribution of films across time periods
  • Cast and crew roles: Breakdown of different job roles in the industry
  • Cast and crew gender: Gender representation in film production
  • Character age groups: Age distribution of characters in films
  • Character sexual orientation: Representation of different sexual orientations

Using the Charts

  1. Select different chart types from the dropdown menu
  2. Hover over chart elements to see detailed information
  3. Charts update automatically when you apply filters or search
  4. Charts show the full dataset regardless of current search results

Navigation and Pagination

Browsing Results

  • Navigate between pages using the pagination controls at the bottom
  • See your current position (e.g., “Showing 26-50 of 1,234 results”)
  • Jump to specific pages by clicking on page numbers
  • Use arrow buttons to go to previous/next pages

URL Sharing

  • Your search state is saved in the URL automatically
  • Share specific searches by copying the URL
  • Bookmark searches for later reference
  • Browser back/forward buttons work with your search history

Tips for Effective Searching

Search Strategies

  1. Start broad, then narrow: Begin with a general search, then use filters
  2. Use specific terms: “female director” works better than just “director”
  3. Combine search and filters: Search for “war” and filter by “drama” genre
  4. Try different spellings: Some names might have alternative spellings
  5. Use partial names: You don’t need to type the full name

Finding Specific Content

  • Looking for films by a director? Search their name and filter by “Director” role
  • Interested in recent films? Use the release year filter
  • Want films from a specific country? Use the production country filter
  • Researching representation? Combine character filters with search terms

Accessibility Features

The data explorer includes several accessibility features:

  • Keyboard navigation: Use Tab to navigate, Enter to activate
  • Screen reader support: All elements have proper ARIA labels
  • High contrast: Works with high contrast mode
  • Focus indicators: Clear focus states for all interactive elements
  • Live regions: Dynamic content updates are announced to screen readers
